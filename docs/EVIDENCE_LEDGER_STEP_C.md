## Current Research Consequence

The universal-guard architecture remains unchanged. `RunScriptFunction` is still recursion-safe pure pass-through; AISetState and AIFullStop remain validated explicit-this `.ThisCall()` member hooks; C1 physical repair is disabled; the known bad held-Use2 path remains a destructive stress case rather than production authority.

EV-201's extended run remains valuable: repeated clean/native-cleanup, pre-activation, armed destructive abandonment, inherited-stale and source-specific controls continued to classify as expected, including 23 real `WOULD_REPAIR` outcomes and only the known seven unowned pre-CombatMove/GetUpAttack warnings. However, EV-202 supersedes EV-201's initial crash-root-cause interpretation.

The exact crashed-DLL disassembly identifies the failing `GetCollisionGroup()` as the one inside `CollisionLifecycleGuard::FinalizeAfterAISetState()`, reached after native AISetState has run, using a remembered raw source pointer whose current liveness was not first established. The higher DLL crash frame is the AISetState wrapper returning from that finalizer. The SetCollisionGroup `.ThisCall()` transport therefore remains **not fully validated but not shown to have failed**: its extended gate was interrupted by this separate C1 observation-lifetime defect after 307 logged SetCollisionGroup blocks.

The next implementation responsibility is a **bounded C1 finalization source-liveness safety correction**. Determine current equipped-source identity using pointer comparison before dereferencing remembered source pointers. If a remembered source is not currently equipped, do not call `GetCollisionGroup()` or other entity methods on that remembered pointer merely for finalization diagnostics/classification. Preserve `UNRESOLVED_NOT_EQUIPPED` for outstanding obligations and `NO_OP_NO_OUTSTANDING` for non-outstanding records without physical repair. If the source is still currently equipped, preserve the existing collision-group observation and `WOULD_REPAIR` / physically-clean reconciliation logic. Do not alter SetCollisionGroup, AISetState/AIFullStop transport, marker semantics, C1-O2, or repair state.
