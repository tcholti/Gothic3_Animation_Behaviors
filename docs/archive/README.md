# Documentation Archive

**Purpose:** Cold historical documentation preserved for provenance and reconstruction but excluded from ordinary project retrieval.

Archive material may include:

- completed probes and causal experiments;
- completed bounded implementation contracts;
- completed audit tasks/results;
- superseded redesign plans/refactor contracts;
- closed evidence-ledger volumes.

Archive does **not** mean unimportant or deletable. It means the reusable conclusions have already been promoted to current reference/architecture/decision authorities.

Ordinary retrieval must not scan this directory. Open an archived document only when a current reference/evidence pointer requires exact historical detail, a contradiction appears, or provenance must be reconstructed.

Subdirectories:

```text
investigations/  closed probes, implementation contracts, audits, superseded work plans
evidence/        closed evidence-ledger volumes
```

The archive preserves original document contents unless a path-only correction is required for navigability.
